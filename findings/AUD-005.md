# [AUD-005] `listWebhookSubscriptions` Hard-Caps at First 100 Subscriptions — No Pagination

- **Finding ID**: AUD-005
- **Severity**: Low
- **Confidence**: High
- **Category**: Reliability
- **Location**: `src/lib/webhooks/integrations/shopify-webhooks.ts` — `listWebhookSubscriptions`

---

## 1. Description & Evidence

The README documents:

> "`listWebhookSubscriptions` reads only the first 100 subscriptions (`first: 100`)"

Shopify's GraphQL API uses cursor-based pagination. This implementation fetches only the first page of 100 webhook subscriptions with no `pageInfo.hasNextPage` check or cursor-continuation. If a Shopify store ever accumulates more than 100 webhook subscriptions (possible in multi-topic or multi-URL scenarios), `registerMissingWebhooks` will silently believe topics are unregistered when they are present on page 2+, potentially creating duplicate subscriptions.

**Canon Reference**: Ref 11 (Nygard Production Stability) — Bounded Result Sets pattern. The spec warns against trusting a fixed-page response as representing the complete data set.

---

## 2. Actual or Credible Failure Scenario

A store's Shopify subscription list grows beyond 100 entries (e.g., historical subscriptions from previous app versions that were never cleaned up, or multiple endpoint URLs). `registerMissingWebhooks` calls `listWebhookSubscriptions`, receives only 100 entries, does not find topic `orders/create` (which is on page 2), and creates a **duplicate subscription**. Shopify delivers webhooks to both old and new URIs, causing double processing of order events.

---

## 3. Technical & Business Impact

- **Technical Impact**: Duplicate webhook subscriptions leading to double-processing of Shopify events; `webhook_events` deduplication by `x-shopify-webhook-id` would catch delivery retries but not genuinely separate delivery calls.
- **Business Impact**: Double `runShopifySync` calls; potential duplicate analytics write; wasted API quota.

---

## 4. Proposed Correction

Implement cursor-based pagination in `listWebhookSubscriptions`:

```typescript
async function listWebhookSubscriptions(store: string): Promise<WebhookSubscription[]> {
  const all: WebhookSubscription[] = [];
  let cursor: string | null = null;
  do {
    const result = await shopifyGraphql(store, {
      query: WEBHOOK_SUBSCRIPTIONS_QUERY,
      variables: { first: 100, after: cursor },
    });
    all.push(...result.webhookSubscriptions.nodes);
    cursor = result.webhookSubscriptions.pageInfo.hasNextPage
      ? result.webhookSubscriptions.pageInfo.endCursor
      : null;
  } while (cursor !== null);
  return all;
}
```
