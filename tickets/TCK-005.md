# [TCK-005] Implement Cursor-Based Pagination in `listWebhookSubscriptions`

- **Ticket ID**: TCK-005
- **Related Finding**: [AUD-005](../findings/AUD-005.md)
- **Phase**: Phase C — Integration Resilience
- **Status**: Draft
- **Assigned Agent**: TBD (Sonnet specialist)

---

## 1. Problem Definition

`listWebhookSubscriptions` fetches only the first 100 Shopify webhook subscriptions with no cursor-continuation or `pageInfo.hasNextPage` check. If a store has >100 subscriptions, `registerMissingWebhooks` silently believes topics are unregistered and creates duplicate subscriptions, causing double event processing. Per Ref 11 (Nygard) — Bounded Result Sets pattern warns against trusting a fixed-page response as representing the complete data set.

---

## 2. Expected Outcome

- `listWebhookSubscriptions` implements cursor-based pagination, fetching all pages.
- `registerMissingWebhooks` correctly identifies already-present topics regardless of their page position.
- GraphQL query updated to include `pageInfo { hasNextPage endCursor }` and `after` variable.

---

## 3. Affected Files & Services

- `src/lib/webhooks/integrations/shopify-webhooks.ts` — `listWebhookSubscriptions` function and its GraphQL query

---

## 4. Acceptance Criteria

- [ ] 1. `listWebhookSubscriptions` loops until `pageInfo.hasNextPage` is `false`.
- [ ] 2. GraphQL query includes `after: $cursor` variable and `pageInfo` fields.
- [ ] 3. `registerMissingWebhooks` correctly skips topics found on page 2+.
- [ ] 4. `npm run typecheck && npm test` pass.
- [ ] 5. No modification of unrelated webhook registration logic.

---

## 5. Regression Test Specification

- **Test path**: `tests/webhooks/shopify-webhooks.test.ts`
- **Expected assertions**:
  - Mock returning `hasNextPage: true` on first call, `false` on second → all items collected
  - `registerMissingWebhooks` with 150 subscriptions does not create duplicates

---

## 6. Risks & Rollback Requirements

- **Risk Assessment**: Low — additive change; no behavioral change for stores with <100 subscriptions.
- **Rollback Procedure**: Git revert; function returns to single-page fetch.
