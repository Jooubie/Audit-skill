# [TCK-010] Add BOM Edge-Case Regression Tests for `readTextCapped`

- **Ticket ID**: TCK-010
- **Related Finding**: [AUD-010](../findings/AUD-010.md)
- **Phase**: Phase D — Architecture & Governance
- **Status**: Draft
- **Assigned Agent**: TBD (Sonnet specialist)

---

## 1. Problem Definition

`readTextCapped` uses `TextDecoder` with `ignoreBOM: true`, preserving any BOM character in the decoded string. While this is correct for HMAC round-trip fidelity with UTF-8 (Shopify's encoding), the interaction with adversarial BOM injection or non-UTF-8 encodings is not explicitly tested. The finding is low-confidence (Shopify always sends UTF-8), but adding regression tests documents the actual behavior and catches regressions if the TextDecoder option changes.

---

## 2. Expected Outcome

- Unit tests cover BOM-prefixed UTF-8 body → HMAC round-trip is lossless.
- Unit test verifies JSON.parse succeeds (or is documented as failing) on BOM-prefixed body.
- Actual behavior is documented regardless of whether it's considered a defect.
